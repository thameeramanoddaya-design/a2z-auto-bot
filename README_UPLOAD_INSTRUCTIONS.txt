A2Z Bot - files to upload to your GitHub repo
==============================================

MEKE THIYENAWA:
  - index.js       -> repo eke ROOT ekata danna (package.json thiyana thanatama)
  - package.json    -> repo eke ROOT ekata danna (mekath root ekatama)

MEKA KARANNE KOHOMADA (GitHub website eken, code type karanna wenne na):

1. github.com yanawa, oyage a2z-auto-bot repo eka open karanawa.
2. Repo eke "Add file" button eka click karala "Upload files" select karanawa.
   (Meka "Add file" kiyana green/white button eka repo file list eke uda dakkaganna puluwan)
3. Me zip eke thiyana index.js saha package.json file deka, computer eken
   drag karala GitHub upload page ekata danawa (nathnam "choose your files"
   click karala select karanawa).
4. Uda scroll karala "Commit changes" (green button) click karanawa.
   - Eka file dekama "main" branch ekatama commit wenna oni (default eka
     hariyata thiyenawa nam ehemai).
5. Repo eke ROOT ekedi thiyena palaveni index.js / package.json thibba nam,
   GitHub eka awashyayenma OVERWRITE karayi (replace) - eka gena kaevatha
   danna oni na, GitHub eka authomatic karaganiyi.
6. Ivara unama, "Actions" tab ekata gihin, "A2Z Automation Bot Run" eka
   "Run workflow" button eken aluthin run karanawa.

MEKA IMPORTANT: .github/workflows/runner.yml file eka wenas karanna oni
na - eka dan repo eke thiyena eka hariyatama vada karanawa. Wenas karanna
oni ekama tikama index.js eka witharai.
